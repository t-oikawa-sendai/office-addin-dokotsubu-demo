# DokoTsubu 風 Excel VBA サンプル — 仕様（ここまで）

## 目的・位置づけ

- Java サーブレット版 **DokoTsubu** を模した **Excel VBA 学習用**の説明用サンプル。
- **本番用途ではない。** 生徒向けに画面構成と画面遷移を追いやすくすることを優先する。
- **主軸は Windows 版 Excel の VBA**（Mac はこの文書時点では主対象外）。

## 対象外（明示的にやらないこと）

| 項目 | 備考 |
|------|------|
| ユーザー登録 | 仕様の対象外 |
| 実認証 | ID／パスワードの検証は未実装（ログインは常にメインへ進む） |
| DB・ファイル永続化 | Step2 以降で検討。現状はメモリのみ |
| シートセルへの直接入力 | 一覧・投稿は UserForm 上のコントロールのみ |

## 画面一覧と役割

| UserForm | ファイル | 役割 |
|----------|----------|------|
| `frmLogin` | `vba/frmLogin.frm` | ユーザーID・パスワード入力、ログイン／キャンセル |
| `frmMain` | `vba/frmMain.frm` | つぶやき一覧、投稿入力、投稿、ログアウト |

## 画面遷移

1. マクロ **`ShowLogin`**（`modEntry`）実行 → `frmLogin` をモーダル表示。
2. **ログイン** → `frmLogin` を閉じ、`frmMain` をモーダル表示。
3. **投稿** → メモリ上のコレクションに追加し、同一フォーム内の一覧を再描画（別画面への遷移なし）。
4. **ログアウト** → `frmMain` を閉じ、`frmLogin` を再表示。
5. **キャンセル**（ログイン画面）→ `frmLogin` を閉じる。

## モジュール・フォームの責務

| 名前 | 種別 | 責務 |
|------|------|------|
| `modEntry` | 標準モジュール | 起動マクロ `ShowLogin`。つぶやき用 `Collection` の保持、`TweetAdd` / `TweetRefreshListBox` |
| `frmLogin` | UserForm | ログイン UI、ログイン成功時に `frmMain` へ |
| `frmMain` | UserForm | メイン UI、一覧の初期表示・投稿後の更新、ログアウトでログインへ |

## データ保持（仮）

- `modEntry` 内の **`Private tweetCol As Collection`**。
- 初回アクセス時に `Collection` を生成し、サンプル文 **1 件**を投入する。
- Excel プロセスが生きている間は **ログアウト後も内容は残る**（学習用のメモリ保持仕様）。
- ブックを閉じてもプロセスによっては変数が残る場合があるが、**永続化はしない**。

## 本家（Java Web）との比較での簡略化

- HTML／CSS／サーバー・セッション・Servlet／JSP の完全再現はしない。
- 認証は UI のみ（検証ロジックなし）。
- 登録、ページング、削除、検索などは未実装（必要なら後から足せる前提）。

## リポジトリ上のファイル

| パス | 内容 |
|------|------|
| `vba/modEntry.bas` | 標準モジュール |
| `vba/frmLogin.frm` | ログインフォーム |
| `vba/frmMain.frm` | メインフォーム |

### `.frx` について

- 現状の各 `.frm` には **`OleObjectBlob`（.frx 参照）がない**ため、**別途 `.frx` ファイルはリポジトリに含めない**想定でよい。
- VBA エディタからエクスポートした形式にした場合は `.frx` が付くことがある。そのときはペアで管理する。

## Excel ブックへの取り込み（開発者向け）

1. マクロ有効の **`.xlsm`** を用意する。
2. VBA エディタで **ファイル → ファイルのインポート**より、`modEntry.bas`、`frmLogin.frm`、`frmMain.frm` をインポートする。
3. マクロ一覧から **`ShowLogin`** を実行する（または図形に割り当てる）。

文字化けする場合は、VBA エディタ上でキャプション等を手直しする。

## 今後の拡張（メモ）
